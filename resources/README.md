List of several resources used in the workflow : 

- `regev_lab_human_cell_cycle_genes` : These 2 files `g2m` and `s` contain the list of human cell cycle genes defined in [Tirosh et al, 2015](https://doi.org/10.1126/science.aad0501). Both files contain 2 columns : `gene_id` and `gene_name` for ensembl gene ids and gene symbols respectively. In case of alternate species, a list of ortologues should be compiled.
